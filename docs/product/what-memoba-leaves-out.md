# What Memoba leaves out

A product is defined as much by what it refuses as by what it does. Memoba's first version does one thing: it helps a team find and reuse its own past work when something new arrives. Everything here was left out so that one thing could be done well.

## Not in this version

| Left out | Why |
|---|---|
| Connectors to wikis, trackers, and chat | They add volume before the answer has earned it, and raw history has already lost its reasoning |
| Cases written with no human review | Experience comes from people. [Import](../engine/how-knowledge-gets-in.md#import-drafts-it-never-saves) drafts, and a person saves |
| Parsing PDF, Word, and slide files | Parsing is its own quality problem. Process documents accept pasted Markdown and `.md` or `.txt` files |
| Web research | The point is your team's own work. General advice is not team experience |
| Several cooperating agents | One agent with three tools covers the questions this version is for |
| Comparing every case on a broad question | One run reads a handful of cases well, and that matters more than skimming all of them. The [next engine step](../engine/how-the-agent-answers.md#the-next-engine-step) addresses this |
| Runs that continue after you leave | A run is tied to its request. A refresh shows saved state and never restarts the model |
| Approval workflows, roles, per-tool permissions | Workspace membership is the access boundary |
| Scheduled document versions | Publishing replaces the current version at once |

## What is shown but not live

Three things in the product preview where it could go. Each one is labelled.

**The Dashboard runs on sample data.** It carries a "Sample data" label and its figures are illustrative. It shows how a team could see whether its knowledge is working: how many answers rest on evidence, which topics had no matching case, and which cited cases still have an unknown outcome.

**Files in Import only show their names.** File contents stay in your browser and are not read. Pasted notes are real.

**Roadmap is marked Soon.** It does nothing yet.

## What Memoba cannot promise

A citation shows that Memoba read a section. It does not show that the section supports the sentence beside it, or that the advice fits your situation. Open it and judge.

One run reads a handful of sources, so a question like "everything we learned about pricing" gets a partial view.

The quality of an answer depends on the quality of what the team recorded. A thin case gives a thin answer.

Memoba has so far answered questions only about fictional records, and no real team has used it yet.
